environment. The environment reports:

  workloadProfiles: [ { name: Consumption, workloadProfileType: Consumption } ]

and that meter is documented against Dedicated workload profiles, so the
expectation is that it is not charged. Expectation is not evidence, hence this
file.

Known fixed cost regardless: ACR Basic at $0.1666/day, for the registry that
holds the pushed image. ACR Tasks is not permitted on this subscription, so the
registry cannot be avoided by building server-side.
